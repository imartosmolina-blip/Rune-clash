# Asistente Taller IA

Aplicación móvil/web independiente dentro del repositorio Rune-clash.

Ruta pública prevista con GitHub Pages:

`/Rune-clash/asistente-taller/`

Incluye:
- accesos rápidos para armarios, cajones, cajoneras, tarifa y croquis;
- regla de consulta basada en la tarifa ESENZIA 4.0;
- apertura de consultas en ChatGPT;
- dictado cuando el navegador lo permite;
- calculadora rápida;
- historial local de consultas;
- manifest para instalación tipo app.

Rune Clash no se modifica.
